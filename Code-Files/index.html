DeepBird — AI-Driven Bird Sound Identification

Classifies audio recordings into bird-species categories using a deep-learning pipeline. Librosa converts audio into spectrogram representations, which a CNN learns to recognize. Trained on a dataset covering 20 bird species with approximately 91% classification accuracy, built with a three-member team with primary responsibility for CNN model training.

  • Python

  • TensorFlow

02

Customer Churn Prediction

End-to-end Flask web app for customer churn prediction. Upload any CSV or use the bundled sample, train Logistic Regression and Random Forest with leakage-safe preprocessing (fitted on 80% training split), compare on Accuracy/Precision/Recall/F1 with confusion matrices, auto-select the best model, view feature importance, and run real-time predictions with dynamic forms.

  • Python
  • Flask
  • Pandas

03

Sales Forecasting & Business Dashboard

An end-to-end Flask sales analytics dashboard that turns historical order data into KPIs, monthly trend and category charts, and a three-month Scikit-learn forecast. Built with chronological train/test splitting to prevent data leakage, holdout MAE/RMSE/R² reporting, CSV upload with graceful handling of optional columns, and live conversion across 7 currencies (PKR, USD, EUR, GBP, INR, AED, SAR). The responsive front end is powered by vanilla JavaScript and Chart.js.

  • Python
  • Flask
  • Pandas
  • Scikit-learn
  • Chart.js
  • JavaScript
